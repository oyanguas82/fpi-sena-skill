# Catálogo de estrategias didácticas por momento

Fuentes: Pimienta, J. (2012). *Estrategias de enseñanza-aprendizaje* (Pearson) y *Manual de Estrategias Didácticas*. Elige 1–3 por actividad y nómbralas en "Estrategias o técnicas didácticas activas".

## INICIO — 3.1 Reflexión inicial
| Estrategia | Cómo se usa | Producto en clase |
|---|---|---|
| Pregunta problémica | Situación real + 2–4 preguntas abiertas | Respuestas individuales → plenaria |
| Estudio de caso breve | Caso corto del sector con un dilema | Postura argumentada |
| Analogía | Relacionar el tema con algo cotidiano | Tabla análogo/real |
| Conversatorio / panel | Diálogo guiado por el instructor | Conclusiones en tablero |
| Juego de roles | Representar actores de la situación | Reflexión grupal |
| QQQ (qué veo, qué no veo, qué infiero) | Analizar imagen/video del contexto | Tabla de 3 columnas |

## INICIO — 3.2 Contextualización / saberes previos
| Estrategia | Cómo se usa |
|---|---|
| Lluvia de ideas | Ideas libres sobre el tema; el instructor las agrupa |
| SQA | Qué sé / Qué quiero saber / Qué aprendí (la 3.ª columna se completa al final) |
| RA-P-RP | Respuesta anterior – Pregunta – Respuesta posterior |
| Preguntas exploratorias / literales / guía | Diagnóstico escrito u oral |
| Cuestionario diagnóstico gamificado | Kahoot, Quizizz, Forms (Aprendizaje Basado en Juegos) |
| Socialización de experiencias | Compartir vivencias laborales previas |

## DESARROLLO — 3.3 Apropiación
**Organizadores (saber):** cuadro sinóptico, cuadro comparativo, matriz de clasificación, matriz de inducción, uve heurística de Gowin, diagramas (radial, árbol, causa-efecto/Ishikawa, flujo), mapa mental, mapa conceptual, mapa semántico, mapas cognitivos (sol, telaraña, ciclos, secuencia, cajas, calamar, algoritmo), mentefacto, línea de tiempo, resumen, síntesis, ensayo, infografía.

**Grupales:** debate, simposio, mesa redonda, foro, seminario investigativo, taller.

**Práctica (proceso):** demostración del instructor → práctica guiada → práctica independiente; simulación; laboratorio; ejercicios prácticos; estudio de caso.

## CIERRE — 3.4 Transferencia
| Metodología activa | Uso típico |
|---|---|
| Aprendizaje Basado en Proyectos (ABP) | Entregable del proyecto formativo |
| Aprendizaje Basado en Problemas | Resolver la situación problémica de 3.1 |
| Estudio de caso completo | Diagnóstico + solución + justificación |
| Simulación | Escenario productivo controlado |
| Aprendizaje in situ / práctica de campo | Visita o trabajo en empresa real |
| Aprender mediante el servicio | Solución para una comunidad u organización |
| Investigación con tutoría / investigación-acción | Indagar y proponer mejora |
| Webquest / Aprendizaje basado en TIC | Investigación guiada en red |
| Aprendizaje cooperativo | Roles interdependientes en equipo |
| Tópico generativo | Proyecto integrador alrededor de un tema eje |

## Por modalidad
- **Presencial:** demostraciones, laboratorio, talleres, exposiciones.
- **Virtual / a distancia:** foros, wikis, webquest, videos, cuestionarios en LMS, sesiones sincrónicas; especifica la plataforma (Territorium, Zajuna, Teams…).

## Herramientas digitales sugeridas
Organizadores: Canva, Lucidchart, draw.io, CmapTools, GoConqr. Diagnóstico: Kahoot, Quizizz, Mentimeter, Forms. Colaboración: Padlet, Miro, Google Docs, Teams. (Ajusta a lo que el centro de formación tenga disponible.)
